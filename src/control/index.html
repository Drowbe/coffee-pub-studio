CP Tavern

SIGNED IN

Coffee Pub Tavern is the voice and video server for the people at your table. Sign in with an admin account and the CP Tavern tab lists everyone; publish a player to give them their own OBS Browser Source.

Participant Source

Their video, or a still image when the camera's off — borders and overlays are set on the Tavern. Audio routes through OBS's own Control audio via OBS toggle.

Character Source

Their character image, transparent until they talk or mute — good for overlaying a character bar.

Someone who's stepped into an ordinary aside gets muted while Enable Asides is on, so their conversation there doesn't bleed into the stream — their source stays on screen either way. Offline sources are left alone; there's no live audio to mute. No visual dim or tint on the Studio side; that's the Tavern server's call now.

Automations

LISTENING

Lets a Foundry module (Herald, for instance) tell Studio when something happens in the game — combat starting, a scene changing — so a rule on the Automations tab can switch an OBS scene, show or hide a source, or start/stop recording. Foundry usually runs on a different machine, so this listens on your network, not just this Mac — the token is what keeps that port private.

Give a Foundry module the address and token below. It sends a POST to <address>/api/automations/event with an Authorization: Bearer <token> header and a JSON body like {"event":"combat:start"}. This is HTTPS, needed so it works from a Foundry page that's itself served over HTTPS — the certificate has to be trusted on the Foundry machine first, or every call from a module will silently fail (nothing shows up in Recent Events below either — that's the tell).

Quick way: click through a warning once (per browser, breaks if this Mac's address changes)

Open the Address below directly in Chrome on the Foundry machine, once, and click through the "not private" warning.

Better way: install the CA certificate once (every browser, every future address, permanently)

Open the CA cert link below in Chrome on the Foundry machine, once — downloads coffee-pub-studio-ca.crt. Then:

On Windows:

  1. Double-click the downloaded file, then click Install Certificate...
  2. Choose Local Machine (needs admin, trusts it for everyone) or Current User → Next.
  3. Choose Place all certificates in the following store → Browse... → Trusted Root Certification Authorities → OK → Next → Finish.
  4. Click Yes on the security warning that shows the certificate's thumbprint.

On a Mac:

  1. Double-click the downloaded file to open Keychain Access's "Add Certificates" prompt.
  2. Set the Keychain dropdown to System (not iCloud) → Add → enter the Mac's password.
  3. In Keychain Access, find Coffee Pub Studio Local CA and double-click it.
  4. Expand Trust, set When using this certificate to Always Trust, close the window and authenticate again — it stays untrusted until this step, even after being added.
